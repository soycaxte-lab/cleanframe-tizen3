# Prompt para un asistente

Copia este texto:

> Ayúdame a instalar https://github.com/soycaxte-lab/cleanframe-tizen3. Lee README.md, docs/TUTORIAL-ES.md y las instrucciones del repositorio. Guíame en español. Comprueba mi modelo, firmware y Tizen antes de afirmar compatibilidad. Usa mis certificados Samsung y una identidad independiente que se conserve para actualizaciones. Usa herramientas oficiales y Samsung Certificate Extension 2.0.74 o posterior; la prueba funcionó con 2.0.75. Déjame completar personalmente licencias, contraseñas e inicio de sesión; no me pidas secretos en el chat. Descubre los IDs reales de mis apps, ajusta el perfil privado y prepara el paquete Tizen 3.0. Comprueba el permiso XML y su ruta SDK. Verifica firmas presentes, identidad y la confirmación install completed: código 0 no demuestra instalación. Anuncia instalaciones, lanzamientos y reinicios y confirma conmigo lo visible. Prueba cada app; usa el acceso alternativo de YouTube cuando corresponda. Prueba inicio automático solo con «última aplicación». No sustituyas Home, no obtengas root ni cambies firmware o instales servicios residentes. Mantén certificados, direcciones, DUID y widgets firmados en almacenamiento privado excluido de Git. Resume qué funcionó en mi TV y qué queda pendiente.
